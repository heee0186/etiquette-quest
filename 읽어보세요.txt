[파일 구성]  index.html만 열면 실행돼요. 네 가지를 같은 폴더에 같이 두세요.
  index.html  화면 뼈대
  style.css   글씨 크기·색·간격 (구역별로 나뉘어 있어요)
  app.js      기능. 맨 위 "1. 쉬운 수정 영역"에 이모지·문구·이름이 모여 있어요
  images/     그림 파일 (아이콘 10개 + 배경 2개)

[자주 하는 수정 - 모두 app.js 위쪽]
  화면 문구(제목·홈 설명·버스 안내 등) → UI_TEXT
  '합숙 N일차'의 '합숙' 글자            → DAY_LABEL  (N은 설정의 시작일·종료일로 자동 계산)
  그림 아이콘(상인·상자·물음표 등)       → ICON_ASSETS (images 폴더의 파일명과 연결, 같은 이름의 PNG로 바꿔 끼우면 돼요)
  수상한 상인 보상 이모지(간식·쿠폰)      → MYSTERY_ICONS
  배지·구간·상점 이모지와 이름            → BADGES / STAGES / STAGE_EVENTS / SHOP
  기본 숫자                               → "2. 처음 기본값"의 settings
  관문 예절 퀴즈 문제·보너스 포인트        → 교사 관리 > '관문 퀴즈' 화면에서 바로 고치고 추가해요
                                          (app.js의 QUIZZES는 '처음 기본 문제'예요)
  성 보물창고 보상(이름·가격 등)          → CASTLE_SHOP
  이야기·칭찬 쪽지 최소 글자 수            → STORY_MIN_LENGTH / PRAISE_MIN_LENGTH
  예절 약속 개수·칭찬 쪽지함 기본 기간     → PROMISE_COUNT / PRAISE_RECENT_DAYS
  전원 제출 보너스(P)                      → 교사 관리 > '목표·상품 설정'
  선택의 길 비용·칸 수                     → 교사 관리 > '모험 설정' (1칸당 평균 비용을 바로 계산해 보여줘요)
  글씨 크기·색·여백                       → style.css

[주의] 설정값(포인트·확률·가격 등)은 브라우저에 저장돼요. app.js의 기본 숫자를 바꿔도
이미 쓰던 기기에서는 저장된 값이 우선이에요. 교사 설정 화면에서 바꾸거나 전체 초기화 후 확인하세요.
(UI_TEXT·DAY_LABEL·MYSTERY_ICONS는 저장되지 않아서 고치면 바로 반영돼요.)

[2.11에서 바뀐 것]
  - 탐험 열쇠: 개수로 쌓이고, 날짜가 바뀌어도 사라지지 않아요. 보물상자 1개에 열쇠 1개를 써요.
  - 선택의 길: 왼쪽은 '안전한 길'(20P → 늘 2칸), 오른쪽은 '모험 길'(30P → 1~5칸).
    1칸당 평균 비용이 기본 이동비와 같아서 더 이상 지름길이 되지 않아요.
  - 칭찬 쪽지: '좋은 행동을 발견했어요'를 고르면 누구의 어떤 행동이었는지 적어요.
    모험 지도 화면의 '칭찬 쪽지함'에 쓴 사람 이름 없이 붙고, 받은 학생은 기록 화면에서 볼 수 있어요.
  - 전원 제출 보너스: 그날 참여 학생 모두가 기록하면 +20P (기록을 지워 전원이 아니게 되면 취소돼요).
  - 실천의 성 마지막 관문 뒤에 '우리 반 예절 약속'을 정해요. 퇴소식 요약에도 들어가요.
  - '꾸준한 기록' 배지: 우리 반이 기록한 날 기준 3번 연속 (입력을 못 한 날은 건너뛰어요).
  - 이야기는 띄어쓰기 빼고 10글자 이상이어야 제출돼요.
  - 홈 화면에 목표 포인트 진행 막대와 완주 보상이 보여요.

[클라우드 저장 - 처음 한 번만 준비]
  1) Supabase 대시보드(7월 버전과 같은 프로젝트) > SQL Editor 에서 supabase_v2.sql 내용을 붙여 넣고 Run.
     → 새 표 etiquette_quest_v2_state 가 만들어져요. 7월 버전 표(etiquette_app_state)는 그대로예요.
  2) 페이지를 열면 '이 기기 클라우드 연결' 화면이 나와요. 7월에 쓰던 교사 계정으로 기기마다 한 번 로그인.
  3) 오른쪽 위 '☁ 저장 완료'가 보이면 연결된 거예요.

  - 여러 기기에서 동시에 기록해도 자동으로 합쳐요 (포인트·아이템 개수는 더하고, 기록은 모두 남겨요).
  - 인터넷이 끊기면 '☁ 이 기기에 저장됨'으로 바뀌고, 다시 연결되면 자동으로 올려요.
  - 다른 기기의 변경은 15초마다(또는 화면으로 돌아올 때) 확인해요.
  - 연결 정보·새로고침 등은 선생님 관리 > 백업·복구 > '클라우드 저장'에 있어요.
  - '전체 초기화'를 누르면 클라우드 내용도 지워져요(모든 기기에서 사라짐).
